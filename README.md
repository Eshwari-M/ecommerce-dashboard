# Dessert E-Commerce Dashboard

A responsive dessert e-commerce website built with React, featuring a modern interface for browsing desserts, viewing products, and managing a shopping experience.

## Features

- Dessert product listing
- Product categories
- Product details
- Shopping cart
- Responsive design
- Interactive user interface
- Modern e-commerce layout

## Technologies Used

- React
- JavaScript
- HTML5
- CSS3
